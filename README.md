# Portofolio

Personal portfolio site built with React, TypeScript, Vite and Tailwind CSS, deployed to GitHub Pages at https://abrardewa.github.io/portofolio.

## Scripts

- `npm start` / `npm run dev` – start the dev server at http://localhost:5173/portofolio/
- `npm run build` – type-check and build to `build/` (for GitHub Pages, served under `/portofolio/`)
- `npm run build:cpanel` – same, but for hosting at the root of your own domain (e.g. cPanel); upload the contents of `build/` to `public_html`
- `npm run preview` – serve the production build locally
- `npm test` – run the tests with Vitest
- `npm run deploy` – build and publish `build/` to GitHub Pages
